# Data Dictionary

| Field | Description |
|---|---|
| patient_id | Synthetic identifier |
| age | Patient age |
| gender | Synthetic demographic field |
| department | Healthcare department |
| admission_type | Emergency, elective, or outpatient |
| length_of_stay | Length of stay in days |
| wait_time_minutes | Patient wait time in minutes |
| readmitted_30d | 1 if readmitted within 30 days, otherwise 0 |
| medication_errors | 1 if a medication error indicator is present, otherwise 0 |
| satisfaction_score | Synthetic patient satisfaction score from 1 to 5 |
